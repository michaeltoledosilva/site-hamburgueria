# BRASA BURGER — demonstração ZMT

Aplicativo em [`site-hamburgueria`](./site-hamburgueria). Repositório local na branch `master`, sem commit ou remoto configurado nesta etapa.

```powershell
Set-Location .\site-hamburgueria
npm ci
npm run build
$env:PORT='3002'
npm start
```

Prévia: http://127.0.0.1:3002/ . Consulte `site-hamburgueria/ENTREGA.md` para validações, mídias e comandos de publicação preparados.
