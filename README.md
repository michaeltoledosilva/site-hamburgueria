# BRASA BURGER — demonstração ZMT

Aplicativo em [`site-hamburgueria`](./site-hamburgueria). Repositório público: [michaeltoledosilva/site-hamburgueria](https://github.com/michaeltoledosilva/site-hamburgueria), branch `master`.

```powershell
Set-Location .\site-hamburgueria
npm ci
npm run build
$env:PORT='3002'
npm start
```

Prévia: http://127.0.0.1:3002/ . Consulte `site-hamburgueria/ENQUADRAMENTO.md` para a correção do recorte mobile e `site-hamburgueria/LATENCIA.md` para a revisão de latência e cores. `site-hamburgueria/ENTREGA.md` preserva o relatório histórico da criação. Nenhuma hospedagem é criada pelos comandos acima.
